# Portfolio - Fatou AMAR

Bienvenue sur le dépôt GitHub de mon portfolio professionnel en ligne.  
Ce site présente mes compétences, mes projets et mon parcours en tant qu'ingénieure Test Logiciel.

## Lien vers le site en ligne

[Accéder au portfolio en ligne](https://amarfatou.github.io/portfolio)

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Git / GitHub
- Outils d'audit accessibilité :WAVE

## Fonctionnalités

- Section **À propos** présentant mon profil
- Section **Compétences** dynamique, alimentée par un fichier 'skills.json'
- Section **Projets** dynamique, alimentée par un fichier 'portfolio.json'
- Section **Contactez-mois** pour me contacter via le formulaire

  Chaque projet contient :

  - une image,
  - une description,
  - un lien vers le code source

- Formulaire de contact avec message de confirmation
